# 像素幸存者 🎮

像素风**幸存者类肉鸽单机游戏**(Vampire Survivors like),纯前端实现,零依赖零素材。
电脑浏览器、手机浏览器都能玩;手机「添加到主屏幕」后可离线当 App 使用。

![玩法](#-玩法) 战斗全自动攻击,你只负责走位走位:杀怪 → 拾取经验宝石 → 升级三选一构筑流派 → 活过 10 分钟击败最终 Boss!

## ✨ 特性

- **9 种武器 × 5 级**:飞刀、魔弹、长弓、环绕法球、闪电、火球、回旋镖、圣水、护盾
- **9 种敌人 + 精英 + 双 Boss**:史莱姆(会分裂)、蝙蝠、骷髅、蜘蛛(突进)、蛮兵、自爆虫(预警殉爆)、岩龟(免击退)、鬼火、死神;5:00 石头守卫、10:00 深渊领主(三阶段弹幕)
- **肉鸽循环**:金币 → 8 种永久强化(商店)→ 解锁法师/游侠 → 下局更强开局
- **完整手感**:伤害数字/暴击、击退、受击闪白、粒子、屏幕震动、磁吸收集、宝箱
- **全程离线**:Service Worker 预缓存,断网可玩;进度存 localStorage
- **程序化音频**:12 种 WebAudio 合成音效 + 可开关 BGM,零音频文件
- **手机优先**:动态虚拟摇杆(手指按哪儿出现在哪儿)、竖屏适配、对象池+空间哈希保证 200+ 敌人 60fps

## 🚀 快速开始

任意静态服务器指向本目录即可,例如:

```bash
# 方式一:Python
python -m http.server 8080

# 方式二:Node
npx serve .
```

浏览器打开 `http://localhost:8080` → 点击「开始游戏」。
开发调试可用 `node tools/dev-server.mjs`(禁用缓存),URL 加 `?dev` 跳过 Service Worker。

### 手机端「随时使用」(PWA)

1. 把整个目录部署到任一静态托管(GitHub Pages / Vercel / Cloudflare Pages 等,需 HTTPS)
2. 手机浏览器打开网址 → 菜单里选「**添加到主屏幕**」
3. 桌面出现游戏图标,点开即玩、**离线可玩**、进度自动保存

> 局内操作:触屏=动态摇杆拖动走位;键盘=WASD/方向键。攻击完全自动。

## 🎯 目标与技巧

- 拾取蓝色(1)/绿色(5)/红色(25)经验宝石升级,三选一构筑武器+被动
- 5:00 小 Boss、10:00 最终 Boss,击败即通关;通关后可进**无尽模式**继续刷金币
- 死亡不掉金币,结算自动入账——去商店买「永久强化」让下一局更顺
- 精英怪(橙圈)必掉宝箱;自爆虫红闪时快跑!

## 📁 结构

```
index.html            入口与全部 UI 骨架
manifest.webmanifest  PWA 清单
sw.js                 Service Worker(改代码后请递增版本号 V)
css/style.css         像素风 UI 主题
js/
  main.js             装配与场景流转(window.__g 为调试句柄)
  sprites.js          53 张像素精灵(字符点阵+调色板,程序化烘焙)
  core/               引擎/相机/输入/存档/音频
  game/               玩家/武器/敌人/刷怪/Boss/升级池/拾取/地图/粒子
  ui/                 HUD/屏幕/虚拟摇杆
tools/
  dev-server.mjs      无缓存开发服务器
  gen-icons.ps1       PWA 图标生成(PowerShell)
  validate-sprites.mjs 精灵数据校验(输出 preview.png 触表)
CONTRACT.md           模块契约(二次开发必读)
```

## 🔧 二次开发

- 所有模块契约(导出签名/事件/精灵名)见 `CONTRACT.md`
- 数值集中在 `js/game/`(武器/敌人/刷怪曲线/升级池),改完刷新即生效
- 改任何文件后需把 `sw.js` 里的 `V = 'pxs-vN'` 版本号 +1,否则线上用户拿不到更新
- 调试参数:`?cheat`(秒升级)、`?fast`(时间加速)、`?dev`(跳过 SW)
