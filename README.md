# 水墨江湖 · 幸存者

> 像素水墨风肉鸽生存游戏，纯前端实现，零外部依赖。
>
> 在线试玩：[qinyin31.github.io/rouge](https://qinyin31.github.io/rouge/)

玩家将扮演水墨江湖中的侠客，在不断涌来的敌群中移动、战斗、升级和构筑武学。坚持 10 分钟击败最终 Boss，或在通关后进入无尽模式挑战更高极限。

## 游戏特色

- **水墨武侠主题**：宣纸底色、墨色战斗表现、朱砂暴击、青色元素联动和像素化武学图标。
- **12 种武器**：剑气、御风、贯日、墨渊、五雷、焚天、回风、墨雨、金钟罩，以及新增的流云扇、暴雨针、引魂灯（已重做为魂火灼烧，与墨雨的墨湿差异化）。
- **12 种内功与防御道具**：力量、专注、疾风靴、生命之心、磁石、觅宝者、聚宝袋、铁甲、暴击之眼，以及新增的玄武盾、金刚体、反震诀（已重新平衡）。
- **武器进化系统**：武器达到满级且对应内功达到 2 级即可触发进化（门槛由 3 级下调至 2 级），进化后质变。
- **多种组合技**：元素、武器和防御之间可以产生联动，包括阴阳相激、感电连锁、殉焰、扇针合流、引魂雷印、灯护金钟等，推荐标签会高亮提示。
- **14 种怪物 + 双 Boss**：除近战、突进、自爆、摆动和精英敌人外，新增远程弹幕（青炉）、区域威胁（泥沼鬼，带 1.05s 预警）、召唤辅助（唤灵使）。
- **怪物图鉴**：主界面新增“怪物图鉴”入口，与组合图鉴同级，可查看所有怪物的外观、数值、出现时间与特性。
- **等级成长**：随等级提升自动获得三维成长（攻击 +6%/级、生命 +8/级、移速 +1.2%/级），配合武器伤害整体 +35% 上调，缓解后期乏力。
- **完整战斗手感**：自动攻击、击退、暴击、伤害数字、受击反馈、闪避冲刺、护盾吸收、反伤、磁吸拾取和 Boss 弹幕。
- **桌面端与移动端适配**：支持键盘、鼠标双击冲刺、虚拟摇杆、移动端冲刺按钮和 PWA 离线游玩。
- **性能保护**：空间哈希查询、视口剔除、粒子与投射物上限、敌方弹幕/危险区域回收，以及帧率无关的物理更新。

## 快速开始

项目是静态前端工程，不需要安装 npm 依赖。请通过 HTTP 服务启动，直接使用 file:// 可能会受到 ES Module 或 Service Worker 限制。

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：项目自带开发服务器（禁用缓存）
node tools/dev-server.mjs
```

然后打开：

```text
http://localhost:8080
```

### 开发调试参数

开发服务器或静态服务器启动后，可以在 URL 后追加以下参数：

- `?dev`：显示开发错误捕获信息。
- `?cheat`：快速获得经验，用于测试升级流程。
- `?fast`：加速游戏时间，用于测试精英、Boss 和通关流程。

例如：

```text
http://localhost:8080/?dev&cheat&fast
```

## 江湖生存指南

### 升级与构筑

- 敌人会掉落经验、金币、回血肉和其他拾取物。
- 每次升级从 3 个选项中选择 1 个；升级面板每次拥有 1 次免费刷新机会。
- 同一种武器最多升至 5 级；武器栏同时最多携带 4 件武器。
- 武器满级、对应内功达到 2 级后，会优先出现金色“进化”选项（原 3 级门槛已下调）。
- 升级卡会根据当前构筑标记“可进化”或“联动”推荐，方便围绕核心流派继续构筑。

### 组合技

- **阴阳相激**：焚天与墨雨产生燃烧、湿身交互，触发蒸汽爆发。
- **感电连锁**：五雷命中湿身敌人时，电弧会跳跃到附近目标。
- **殉焰**：燃烧中的敌人死亡后留下火区。
- **扇针合流**：流云扇的风痕与暴雨针结合，触发潮刃爆发。
- **引魂雷印**：引魂灯标记目标，五雷命中时追加雷印伤害。
- **灯护金钟**：引魂灯与金钟罩联动，释放引魂灯时补充护盾。

进化与联动推荐阈值已从心法 3 级下调至 2 级，更容易成型。

### 怪物与图鉴

- **常规**：纸妖（分裂）、夜枭（摆动）、骨卫、蛛妖（突进）、青炉（远程弹幕）、金刚力士、火药童子（自爆）、泥沼鬼（预警泥沼）、铁甲龟（免击退）、青灯鬼火（正弦）
- **特殊/Boss**：唤灵使（召唤+光环）、黑无常（精英）、石像守卫（300s Boss）、无常尊者（600s 最终Boss，三阶段）
- **泥沼鬼优化**：地面泥沼现在有 1.05s 预警期（浅色预警圈 + “泥沼涌动!”提示），冷却从 3.8s 延长至 6.2s，给足规避窗口。
- **怪物图鉴**：主菜单新增“怪物图鉴”按钮，界面与“组合图鉴”一致，左侧列表、中间舞台演示、右侧数值与特性说明，支持常规/特殊双标签切换。

### Boss 血条修复

修复 Boss 死亡后血条残留问题：HUD 现同时校验 `hp > 0`，死亡或血量归零立即隐藏并清零填充；Boss 死亡事件确保 `g.boss` 置空，切换局或重开时强制隐藏。

## 操作方式

### 电脑端

- `WASD` / 方向键：移动。
- `Space`：冲刺。
- 鼠标双击方向：快速冲刺。
- `R`：升级面板中刷新选项（每次升级限 1 次免费刷新）。
- `Esc`：暂停。

### 移动端

- 使用屏幕左下角虚拟摇杆移动。
- 使用屏幕右下角冲刺按钮进行闪避。
- 页面支持竖屏适配和添加到主屏幕。

## 开发与验证

修改模块接口或事件时，请先阅读 `CONTRACT.md`。项目使用原生 ES Modules，模块之间通过既有 `Engine` 和 `Bus` 接口协作。

常用验证命令：

```bash
# 检查所有 JavaScript 语法
node --check js/main.js

# 校验精灵资源
node tools/validate-sprites.mjs

# 运行回归测试
node tools/test-hp-finite.mjs
node tools/test-scaling.mjs
node tools/test-characters-boss.mjs
node tools/test-feature-removals.mjs
node tools/test-rec.mjs
node tools/test-rec2.mjs
```

如果修改了前端资源，发布前需要递增 `sw.js` 中的缓存版本号 `V = 'pxs-vN'`，否则已安装 PWA 的用户可能继续使用旧缓存。
