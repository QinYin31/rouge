# 水墨江湖·幸存者 🎋

> ▶️ **在线试玩:https://qinyin31.github.io/rouge/**
> 手机打开后「添加到主屏幕」即可离线当 App 玩 · 电脑点击即玩
=======

**水墨武侠风**幸存者类肉鸽单机游戏(Vampire Survivors like),纯前端实现,零依赖零素材。
宣纸为纸,墨色为兵——杀敌、拾青焰、悟武功,活过十分钟,败「无常尊者」。

## ✨ 特性

- **水墨武侠世界**:宣纸底、墨色侠客、青灯鬼火、墨圈剑气、竖排书法与朱砂印,全套像素水墨美术(63+ 精灵,程序化烘焙,零图片文件)
- **9 门武功 × 5 级**:剑气、御风、贯日、墨渊、五雷、焚天、回风、墨雨、金钟罩
- **⚔️ 武器进化合成**:武功满级 + 绑定心法满级 → 进化绝学——剑气+力量=**万剑归宗**、御风+专注=**风卷残云**、五雷+聪慧=**九天神雷**、焚天+生命=**焚天煮海**、金钟罩+暴击=**雷动金钟** 等 9 种,形态与伤害质变
- **☯️ 武器协同联动**:焚天点燃 + 墨雨浸润 → **阴阳相激**蒸汽爆发;湿身之敌遭五雷 → **感电连锁**;燃身之敌倒下留下**殉焰**火区
- **💨 冲刺闪避**:电脑空格键 / 双击方向键 / 手机冲刺钮,短距瞬身穿过敌群(无敌帧,冷却随专注/疾风靴缩短);基础移速 +18%
- **肉鸽循环**:局内升级构筑、金币解锁 剑客/道人/游侠;5:00 石像守卫、10:00 **无常尊者**(独立高血量多阶段弹幕),通关后无尽模式
- **完整手感**:墨字伤害数字、朱砂暴击、击退、受击闪白、震屏、磁吸收集、宝箱;12+ 种 WebAudio 程序化音效与 BGM,零音频文件
- **手机随时用**:PWA 离线缓存、动态虚拟摇杆、竖屏适配;空间哈希 + 分块地图缓存 + 视口剔除,200+ 敌同屏流畅

## 🚀 快速开始

```bash
python -m http.server 8080     # 或 npx serve .
```

浏览器打开 `http://localhost:8080` → 「开始游戏」。
开发调试:`node tools/dev-server.mjs`(禁缓存),URL 加 `?dev`;`?cheat` 秒升级、`?fast` 时间加速。游戏默认 120Hz 物理步进,渲染自动跟随设备刷新率。

### 手机端(PWA)

1. 部署到任一静态托管(GitHub Pages 已配置:`Settings → Pages`)
2. 手机浏览器打开网址 → 「添加到主屏幕」→ 离线可玩、进度自动保存

## 🎯 江湖生存指南

- 拾青焰火种升级;三选一构筑武功与心法,**每级附 1 次免费刷新**(按钮或 R 键)
- **武功升到 5 级 + 对应心法 5 级** → 升级出现「⚡进化」卡,悟出进化绝学
- 剑气是贯穿扇形剑气浪,墨雨专砸怪物最密处;焚天点火、墨雨泼水,试试「阴阳相激」
- 被围了就**按空格或双击方向**冲出去;精英掉宝箱
- 死亡不掉金币——积攒金币解锁新角色,再战江湖

## 📁 结构

```
index.html            入口与 UI 骨架
manifest.webmanifest  PWA 清单
sw.js                 Service Worker(改代码后递增版本号 V)
css/style.css         水墨 UI 主题
js/
  main.js             装配与场景流转(window.__g 调试句柄)
  sprites.js          63+ 水墨像素精灵(字符点阵+调色板)
  core/               引擎/相机/输入(含冲刺)/存档/音频
  game/               玩家/武器(含进化)/敌人(含元素状态)/刷怪/Boss/升级池/拾取/地图(分块缓存)/粒子
  ui/                 HUD(含属性面板/冲刺钮)/屏幕/虚拟摇杆
tools/
  dev-server.mjs      无缓存开发服务器
  gen-icons.ps1       水墨 PWA 图标生成
  validate-sprites.mjs 精灵数据校验(preview.png 触表)
  test-scaling.mjs      普通怪/精英血量曲线与后期保底检测
  test-feature-removals.mjs  功能移除与默认物理帧率检测
CONTRACT.md           模块契约 v1/v2(二次开发必读)
```

## 🔧 二次开发

- 模块契约(导出签名/事件/精灵名/进化矩阵)见 `CONTRACT.md`

- 武侠命名对照与数值表都在 CONTRACT v2 与各模块头部
